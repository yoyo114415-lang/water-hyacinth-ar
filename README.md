# 水生植物 3D Web-AR 互動學習平台

> 實作任務：漂浮性水生植物 ── 布袋蓮 (Water Hyacinth)  
> 製作團隊：第 3 組 ｜ 綠境探索隊 (E-Learning Team 03)  
> 線上體驗網址：https://yoyo114415-lang.github.io/water-hyacinth-ar/

## 專案亮點
1. **生成式 AI 與 Blender Script 程序化建模**：運用 `build_water_hyacinth_model.py` 產出輕量化 `water_hyacinth.glb` (289 KB)。
2. **Web-AR 即時相機鏡頭透視**：手機鏡頭對準 AR Code 圖檔，相機實景畫面上立即浮現 3D 布袋蓮模型。
3. **手機手勢與原生 AR**：支援 360 度旋轉縮放、四大關鍵生物特徵熱點解說，並相容 WebXR 原生空間 AR。
4. **完整繳交檔案**：包含平台 QR Code、AR Code 辨識圖與後端 `Code.gs`。
